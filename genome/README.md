# id8Labs Genome

The brand's DNA, in the production path — so every asset is **on-brand by construction**, not corrected after the fact. This is the GENOME core of [HALO](https://github.com/eddiebelaval/HALO) (Holistic Attuned Layered Orchestration) instantiated for id8Labs.

| File | Gene | Dictates |
|---|---|---|
| [`DESIGN.md`](./DESIGN.md) | how it **looks** | palette, type, space, components, motion, anti-design |
| [`VOICE.md`](./VOICE.md) | how it **sounds** | register, lexicon, rules, anti-voice |
| [`ETHOS.md`](./ETHOS.md) | who they **are** | positioning, values, the "would never" list |
| [`genome.json`](./genome.json) | machine layer | hex, families, rule lists — for programmatic checks |
| [`AGENT.md`](./AGENT.md) | enforcement | the contract every producing agent reads first |

**Evidence / ground truth:** `public/shipped/` (the canonical "Shipped." editorial reference), `content/essays/`, and the live site. The applied DESIGN gene (React kit + composition rules) lives in [`docs/EDITORIAL_SYSTEM.md`](../docs/EDITORIAL_SYSTEM.md).

The Genome is **brand-scoped**: it governs every id8Labs surface and every engagement. Any agent — human-driven or autonomous — producing for id8Labs starts at `AGENT.md`.
