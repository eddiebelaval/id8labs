The Key · how to read the table

A cell

21A7 AtAttunement

Z atomic number (top left): a permanent id, assigned in admission order. A mass (top right). Symbol and name. Click any cell for its full card: job, isotopes, origin star, compounds.

Rows — mass (period)

How heavy the machinery is. Mass A = d + s + t, each scored 0–3:

  • d judgment — 0 deterministic → 3 a human decides
  • s state — 0 stateless → 3 corpus-bearing
  • t trust — 0 internal → 3 money, privilege, identity
  • Period 1 (A0–1) primordial: every business is born with these
  • Period 2 (A2–3) light metals: state enters
  • Period 3 (A4–5) heavy metals: judgment enters
  • Period 4 (A6+) the forged series: corpus, money, people

Columns — valence (group)

The bonding contract: what a primitive accepts and emits. Same column = substitutable in a chain. The ten groups are labelled across the top:

  • Initiators begin work · Resolvers fetch truth
  • Intakes record arrivals · Keepers hold
  • Transformers make · Routers choose a path
  • Provers verdict · Gates permit · Emitters send
  • Meters count and account

Status

  • stable — primordial or recurred (N≥2)
  • candidate (N=1) — forged once, provisional
  • promotion candidate — a prediction that already recurs; may admit now
  • eka- predicted — a named gap, not yet forged
  • no known element
